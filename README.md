# یخچال من (My Fridge) 🍳

اپلیکیشن موبایل فارسی بر پایه **React Native & Expo** با طراحی نوستالژیک و الهام‌گرفته از رابط کاربری سیستم‌عامل‌های رترو دهه ۱۹۹۰ (Vintage 1990s Desktop UI).

![رابط کاربری رترو یخچال من](./assets/icon.png)

## 🌟 ویژگی‌های برجسته

- 🖥️ **طراحی نوستالژیک و رترو دهه ۹۰**: قاب‌های پنجره با هدر نارنجی، حاشیه‌های ضخیم مشکی (`#171412`)، سایه‌های سخت ۳بعدی و دکمه‌های کنترلی کوچک (`_`, `□`, `✕`).
- 🧊 **فرم ثبت نام یخچال**: قابلیت شخصی‌سازی و نام‌گذاری یخچال خانگی.
- 📦 **مدیریت موجودی یخچال**: نمایش کارت‌های مصور مواد غذایی (تخم‌مرغ، گوجه‌فرنگی، سیب‌زمینی، پنیر، شیر، پیاز) همراه با شمارشگر و دکمه‌های افزایش و کاهش.
- ➕ **افزودن مواد غذایی دلخواه**: پنجره اختصاصی برای افزودن مواد غذایی جدید با انتخاب واحد، دسته‌بندی و آیکون رترو.
- 👨‍🍳 **موتور پیشنهاد هوشمند غذا («امروز چی بپزم؟»)**: سنجش خودکار درصد هم‌پوشانی موجودی یخچال با نیازمندی‌های هر دستور پخت، همراه با نوار پیشرفت قطعه‌ای رترو.
- 📖 **دفترچه دستور پخت گام‌به‌گام**: مراحل پخت مرحله‌به‌مرحله با چک‌لیست موجودی مواد و نکات طلایی سرآشپز.
- ⏱️ **تایمر رترو پخت و پز**: زمان‌سنج دیجیتال با نمایشگر ۷-سگمنت سبز و زنگ اتمام پخت.
- 🧭 **نوار ناوبری ثابت (Bottom Bar)**: ۳ تب اصلی: خانه، آشپزی، دستور پخت.
- 🇮🇷 **پشتیبانی کامل از زبان فارسی و راست‌چین (RTL)** و ارقام فارسی.

## 🚀 راه‌اندازی و اجرا در محیط توسعه

### پیش‌نیازها
- **Node.js** (نسخه ۱۸ به بالا)
- **npm** یا **yarn**

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای تست‌های خودکار
```bash
npm test
```

### بررسی تایپ‌های تایپ‌اسکریپت
```bash
npm run typecheck
```

### اجرای اپلیکیشن در Expo
```bash
# وب
npm run web

# اندروید
npm run android

# آی‌او‌اس
npm run ios
```
